# QRipple

Scan once. Share everywhere.

## Real-time QR Code Sharing

QRipple now includes real-time QR session sharing:

- Create a temporary share session
- Update text/URL payloads live
- Subscribers in the same session receive updates instantly
- QR image regenerates on every update

## Run locally

```bash
npm install
npm start
```

Then open `http://localhost:3000`.

## Test

```bash
npm test
```
